# 搜救資訊離線版

手機用的搜救案件資訊 PWA：案件摘要、離線地圖（預設魯地圖）、GPS／TWD97 座標工具、任務分組與檢查清單。加到主畫面後，沒有網路也能使用。

## 個資原則

- 網站本身**不含任何案件資料**。案件是 JSON 檔，隊員在「案件」頁匯入，只存在自己手機（IndexedDB）。
- `private/` 放含個資的案件檔，已列入 `.gitignore`，**不要提交、不要部署**。用 LINE 群組等搜救人員管道傳遞。

## Google 登入同步（權限控管）

案件 JSON 與 GPX 放在 Google Drive 資料夾，**只分享給搜救人員的 Google 帳號**。隊員在「案件」頁按「以 Google 登入並同步」，App 會下載該資料夾內的案件檔存到手機，之後離線也能看。

- 能讀到什麼完全由 Drive 共用設定決定：沒被分享的帳號會看到「沒有權限」。
- 某人被移除權限後，他下次同步時，手機上從 Drive 來的案件與航跡會被刪除（手動匯入的不受影響）。若手機一直不再連線同步，已下載的資料仍會留著。
- Drive 上刪掉的案件檔，同步時也會從手機移除。
- 資料夾內 `<案件 id>` 開頭的 `.gpx` / `.kml`（例如 `mudanyan-2026-10_D2搜索.gpx`）會自動掛到該案件的地圖。

### 一次性設定（資料組）

1. 到 [Google Cloud Console](https://console.cloud.google.com/) 建立專案，啟用 **Google Drive API**。
2. 「OAuth 同意畫面」：使用者類型選「外部」，加入範圍 `drive`（讀寫，App 儲存時要上傳案件檔）。
   未送審前為「測試」狀態，最多 100 位測試使用者，需把隊員 Gmail 逐一加入「測試使用者」；人數更多或要免加名單，需送 Google 審查（`drive` 屬受限範圍）。若協會有 Google Workspace，選「內部」即可免審查。
3. 「憑證」→ 建立「OAuth 用戶端 ID」→ 類型「網頁應用程式」，「已授權的 JavaScript 來源」加入部署網址（例如 `https://<帳號>.github.io`）與 `http://localhost:5173`。
4. 把用戶端 ID 和資料夾 ID 填進 `js/config.js`（全隊預設），或請隊員在 App ⚙︎ 設定頁填入。兩者都不是機密。

## 裝備清單

右上角 ⚙︎ 設定 →「裝備清單」可依案件新增、刪除、排序項目與分類，或從東搜預設清單／其他案件複製。

- 「儲存並上傳」：立即套用到這支手機的任務頁（已勾選的項目會保留勾選），並上傳到 Drive，全隊同步後就會一致。

## 本機執行

```bash
npm run serve
```

開啟 http://localhost:5173 。Service Worker 需要 `localhost` 或 HTTPS。

## 測試

```bash
npm test
```

涵蓋 TWD97 轉換（與 proj4 對照，誤差 < 1 cm）、GPX/KML 解析、案件檔驗證。

## 部署（例：GitHub Pages）

把專案（不含 `private/`）推到 GitHub repo，在 Settings → Pages 選分支即可。任何 HTTPS 靜態主機都可以。

**每次修改 App 檔案後，把 `sw.js` 的 `VERSION` 加 1**；新增檔案時也要加進 `SHELL` 清單，否則離線時會缺檔。

## 隊員使用流程

1. 有網路時開啟網址 → 加到主畫面（iPhone：Safari 分享 →「加入主畫面」）。
2. 「案件」→ 匯入案件 JSON。
3. 「地圖」→ ⤓ 下載案件搜索範圍圖磚；☰ 可匯入 GPX/KML 航跡。
4. 進山後：「定位」頁看 TWD97 座標、複製回報字串、打點；地圖長按可加標記或補上待補座標。

## 製作新案件

**建議用 App 內的案件編輯器**：「案件」頁按「＋ 新增案件」，或在案件的「⋯」／摘要頁底部按「編輯案件資料」。

- 依「東搜搜救紀錄 v1.1」段落分區填寫；穿著、聯絡人、行程、分組、每日紀錄、標記等可逐筆新增、排序、刪除。
- 座標欄可輸入「緯度, 經度」或「TWD97 X Y」，也可按 📍 在地圖上點選；搜索範圍按 🗺 用地圖框選。
- 填寫中自動存草稿，離開頁面不會遺失。
- 案件代號由程式自動產生（通報日期＋4 碼，例如 `2026-10-11-k3x9`）。
- 按「儲存並上傳」會存到本機並直接上傳到 Drive 資料夾；離線時先存本機，下次同步自動補傳。若 Drive 上的版本已被別人改過，會先詢問是否覆蓋。

也可以手動複製 `cases/template.json`，依 `cases/schema.md` 填寫。範例：`private/mudanyan-2026-10.json`（2026.10 牡丹岩案）。
